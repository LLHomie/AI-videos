# 卖掉的十年 回来找我了

故事一 EP02 上中下分镜与对白  V2.0  2026年9月28日

本版替代V1.0“招募接班”故事。七七受托寻找老板当年卖掉的十年，带回已独立生活的年轻人。老板拒卖又求购，被两人拒绝后自然死亡。没有强制成交，没有突然妥协，没有幕后评估。

## 世界规则与动机

卖掉的岁月会成为另一个人，自分离起倒数约定年限，并记得分离前的经历；原主人同期继续生活，不是穿越。十年前，二十岁的老板出售十年，因此本篇老板约三十岁；旧人物册43岁经理形象在本篇停用。年轻人约二十岁外形，与老板保留同一脸部骨架和虎口疤，以发型、衣着及疲态区分；新参考图尚未制作。

交易须双方自愿确认，允许分钟、秒的小额转让；强按手签无效。只有同时确认才划转寿命，单方意向不生效。老板没签，七七没有暗扣他的命。年轻人不知道老板会不会卖，来碰碰运气；买不成就离开，不接受用钱卖掉自己最后的时间。

七七收的是早已拖欠的寻人佣金，交付找到的人即可结清，不是保证买回十年的购命款。她知道年轻人接近寿命终点，仍坚持先收欠款；她愿撮合反向购买，但不免费赠命，也不再出售自己的寿命给老板。最后不收年轻人的成交佣金，因为没有成交。
