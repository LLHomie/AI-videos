# 卖掉的十年 回来找我了

## V3.0 修订脚本与即梦逐镜提示词

日期：2026-09-29。当前版本替代V2.0的29秒限制；上中下暂排50／70／65秒，共185秒。时长是首次剪辑建议，不是硬指标；配音、停顿与观众理解优先，实际录音尚未验证。

### 剧情与人物锁定

七七替老板寻找被卖掉的十年，收的是拖欠的寻人佣金，不承诺续命。年轻人就是被卖掉的岁月，保有分离前记忆，独立生活了十年，现在只剩几分钟。他想花最后一块钱买老板余下的时间，多陪楼下的猫。老板认出他后强索寿命，随后发现十年已经耗尽；拒卖自己的时间，再高价求购别人的时间，始终没有妥协。年轻人和七七都拒绝出售，老板自然归零。没有成交、没有夺命、没有突然赠命。

卖掉的岁月化为独立个体，外形保留分离时约20岁的模样；本篇十年前分离，老板实际约30岁，临终疲态可以显老。沿用现有经理三视图的脸和西装作为老板视觉参考，不沿用旧人物册43岁的年龄。年轻人用刚完成的经理青年版。两人右手虎口同一短斜疤，左腕显示寿命；疤痕局部需要统一补绘，不假称已有资产包含清楚特写。

七七用用户提供的新三视图。老板为既有C04；年轻人为C08。全片只有三位人物，猫只在台词中出现。公司Logo可背景出现，不揭幕后Boss。

### 即梦使用方法

先用人物参考生成每镜竖屏静帧，验脸、服装、手和空间关系，再把选中的静帧作为图生视频起始图片。每镜下面的两个代码块分别用于出静帧和做动态，不要将整集台词一并粘入视频提示词。

上传参考时按镜头所需选人：七七=C01_LinQiqi.png；老板=C04_ZhouQinian.png；年轻人=C08_年轻人_经理青年版.png。三视图是身份参考，要求输出单个镜头而非三个人物角度；检查没有把三视图三个角度生成为三个角色。多人物镜头使用各自参考，若当前App模式不支持多参考，先分别出人像与场景，再用可用的画布／编辑流程合成审核后的静帧，不盲目仅靠姓名维持身份。

代码块已含场景和动作，可逐镜复制。镜头标注秒数是剪辑占用，不是保证App可一次生成对应时长。实际模型、可选时长、参考入口以你App当前界面为准；不足时拆两段或用静帧反应补足，不能为凑秒数让动作无意义循环。画面无对白亦可，人物语音和音效后期统一；需要口型时在锁定配音后另行匹配，不承诺文本自动对口型。

寿命数字、手机凭证、公司Logo和“双方自愿确认”字样统一后期叠加。它们承担剧情信息，不能使用模型随机字。先生成空白道具底图。

### 场景与镜头轴线

主机位看向办公桌：老板在画面右，七七在左，年轻人靠左后方门口，随后移至桌左侧抽屉旁。所有正反打在桌面人物连线同侧；人物侧向目光保持一致。先出一张通过审核的办公室全景作为空间参考，再生成近景。背景布局不因切镜改变。

场景底图提示词：竖屏9:16，都市悬疑二维手绘插画，普通旧办公室，一张深色木桌，桌后老板椅，桌左侧有可打开的底层抽屉，左后方磨砂玻璃门，冷白顶灯，简洁墙壁挂钟，桌面有未签纸张和手机，无人，无可读文字，无品牌，地面与家具位置清楚。不要夸张豪宅办公室。

### 倒计时与剪辑

故事内三集连续发生，不插回顾或时间省略。老板全片0秒02:40；50秒01:50；100秒01:00；120秒00:40；156秒00:04；160秒归零。年轻人全片100秒03:00；120秒02:40；160秒02:00；185秒01:35。仅在需要的镜头显示，不必每镜都拍手腕。

镜头若加长或删短，统一重新计算所有出现的数字：老板=max(160－全片秒数,0)，年轻人=280－全片秒数。若死亡镜头时点移动，则重设老板起始值；不要只改某一屏。画面时码含停顿和反应，不含平台封面或片外片头。

### 本版补清楚的四件事

1. 上集先说“只管找人，不包续命”，解释佣金性质。
2. 中集用旧疤匹配切镜和“卖掉的岁月也会自己过日子”解释身份，避免让观众误认父子或穿越。
3. 强签失败发生在镜头里，双方自愿的规则前置。
4. 下集保留拒卖、反向求购、拒救、死亡后的停顿和猫的完整一句话，结局不靠突然妥协。
