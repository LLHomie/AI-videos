# 《卖掉的十年》V4.0 交付说明

本目录是2026年10月6日更新的当前生产版本。V3.1保留在历史交付目录，不覆盖、不删除。

## 文件

- [完整分镜与即梦提示词](卖掉的十年_V4.0_完整分镜与即梦提示词.md)：18个10秒段落、54个分镜、总时长180秒，包含分镜设计、台词、音效、静帧提示词与图生视频提示词。
- [所有场景提示词](所有场景提示词_V4.0.md)：5组无人空镜提示词，用于办公室、桌面与抽屉、入口与走廊、墙角硬币和楼下巷道的空间一致性校准。

## 当前锁定

- 画幅：竖屏9:16。
- 风格：真人实拍电影剧照质感，中国都市现实悬疑，低饱和冷钢灰色调。
- 角色：七七使用C01，Zhou使用C04，年轻人使用C08。
- 手部线索：寿命倒计时统一在右手腕；Zhou与年轻人的右手虎口保留同位置短斜旧疤。
- 办公室：深灰棕横木纹桌、黑色皮椅、深炭灰模块化护墙板、黑色文件架、不锈钢门框与深炭灰双开门。
- 入口光线：门外冷白强光从门缝斜射，在深灰地面形成狭长锐利光斑。

## 与V3.1的主要变化

- 30镜、185秒调整为54镜、180秒，每个10秒段落固定拆为3镜。
- 磨砂玻璃隔断与磨砂门不再作为当前空间基线，改为深炭灰护墙板、文件架和深炭灰双开门。
- 逐镜静帧与动态图生提示词按新空间资产重新描述。
- 新增5组完整无人空镜提示词，供先锁空间、再生人物镜头。

## 使用顺序

1. 先用场景提示词生成并锁定5组空间参考。
2. 再按完整分镜逐镜上传C01、C04、C08对应人物参考。
3. 倒计时、手机内容、合同文字和Logo统一后期叠加，不让模型直接生成。
4. 相邻镜头验收人物位置、视线、手势、道具、门与光斑位置后，再进入图生视频。
